ربط جوجل خطوة بخطوة

النسخ الاحتياطي على الدرايف، والكاليندر، وروابط جوجل ميت، والدخول بجوجل. بتعمله مرة واحدة.
1. المشروع2. الـAPIs3. Branding4. الصلاحيات5. النشر6. الـClient7. الربطالأخطاء وحلولها

قبل ما تبدأ

  • محتاج حساب جوجل (Gmail). للنسخ الاحتياطي استخدم إيميل صاحب السيستم، لأن نسخ كل العملاء هتتحفظ على الدرايف بتاعه.
  • كل الخطوات من Google Cloud Console، وكلها مجانية.
  • مشروع جوجل واحد يكفي لكل السيرفرات ولكل العملاء.

1. المشروع

  1. افتح Google Cloud Console، ومن فوق اختار المشروع أو اعمل مشروع جديد (New project).
  2. اتأكد إن اسم المشروع ظاهر فوق قبل أي خطوة، عشان كل اللي جاي يتعمل على نفس المشروع.

2. تفعيل الـAPIs

افتح كل رابط واضغط Enable:

  • Google Drive API (النسخ الاحتياطي)
  • Google Calendar API (روابط ميت في الكاليندر)
  • Google Meet API (تسجيل الاجتماعات)

3. Branding وAudience

  1. افتح Google Auth Platform واضغط Get started.
  2. App Information: اسم التطبيق (اسم نظامك) وإيميل الدعم.
  3. Audience: اختار External. متختارش Internal، دي لحسابات شركة Google Workspace بس.
  4. Contact Information: إيميلك، وبعدين وافق على الشروط واضغط Create.
جوجل هيكتب إن التطبيق هيبدأ في وضع التجربة (Testing). ده طبيعي، وهنغيّره في الخطوة 5.

4. الصلاحيات (Data Access)

  1. من القايمة: Data Access ← Add or remove scopes.
  2. دوّر وعلّم على التلاتة دول:
    • https://www.googleapis.com/auth/drive.file
    • https://www.googleapis.com/auth/calendar.events
    • https://www.googleapis.com/auth/meetings.space.created
  3. اضغط Update وبعدين Save.
صلاحية drive.readonly (قراءة فولدرات الدرايف للتعلم) اختيارية. لو ضفتها، جوجل هيعتبر التطبيق «مقيد» وهيوري المستخدم تحذير، وممكن يطلب مراجعة. ضيفها بس لو هتستخدم الفولدر المربوط بالتعلم.

5. النشر (Publish app): أهم خطوة

  1. من القايمة: Audience.
  2. تحت Publishing status هتلاقي Testing. اضغط Publish app ← Confirm.
  3. لازم تبقى In production.
لو سبته Testing: محدش يقدر يربط غير الإيميلات اللي في Test users، وأي ربط بيقف لوحده بعد 7 أيام. ده كان سبب وقوع النسخ الاحتياطي.

6. عمل الـClient

  1. من القايمة: Clients ← Create client ← النوع Web application.
  2. Authorized JavaScript origins: عنوان كل سيرفر من غير مسار، مثلاً:
    • https://your-domain.com
  3. Authorized redirect URIs: رابطين لكل سيرفر، واحد للربط وواحد للدخول بجوجل:
    • https://your-domain.com/?drive_cb=1
    • https://your-domain.com/?google_cb=1
    الرابط الصح لكل سيرفر مكتوب على صفحة النسخ الاحتياطي فيه، بزرار نسخ.
  4. شيل العلامة من «Use this client for an AI-powered agent».
  5. اضغط Create. هيطلعلك Client ID وClient secret: انسخهم واحفظهم في مكان آمن، ومتبعتهمش في شات أو رسالة.
جوجل بيقول إن التعديل في الـClient ممكن ياخد من 5 دقايق لكام ساعة. لو الربط رفض على طول بعد التعديل، استنى شوية وجرب تاني.

7. الربط من اللوحة

ربط السيستم (السوبر أدمن)

  1. اللوحة ← الصحة والتقرير والنسخ الاحتياطي ← نسخ احتياطي على جوجل درايف.
  2. الصق الـClient ID والـClient secret واضغط اربط جوجل.
  3. اختار حساب جوجل ووافق على الصلاحيات. لو ظهرت «Google hasn't verified this app»: اضغط Advanced ← Go to … (unsafe) ← Continue.
  4. هترجع للوحة ومكتوب «متصل» وجنبه الإيميل.

ربط العميل لحسابه

  1. صاحب اللوحة: حسابي ← كارت «حساب جوجل» ← اربط حساب جوجل بتاعي.
  2. العميل مش محتاج Client ID: بيستخدم نفس تطبيق السيستم.

قراءة فولدرات الدرايف (اختياري)

زرار اسمح بقراءة فولدرات الدرايف بيضيف الصلاحية على نفس الربط من غير ما يمسح اللي قبلها.

اتأكد إنه شغال

  • في صفحة النسخ الاحتياطي اضغط «نسخ دلوقتي» واتأكد إن ملفات اترفعت.
  • كل يوم الساعة 10:13 السيستم بيجرب الربط، ولو وقف بيوصلك تنبيه على الواتساب، والكارت بيكتب «واقف» وجنبه زرار «اربط تاني».

Connect Google, step by step

Drive backups, Calendar, Google Meet links and Google sign-in. Done once.
1. Project2. APIs3. Branding4. Scopes5. Publish6. Client7. ConnectErrors and fixes

Before you start

  • You need a Google (Gmail) account. For backups, use the system owner's account: every client's backup is saved on its Drive.
  • Everything is done in Google Cloud Console, free of charge.
  • One Google project serves every server and every client.

1. Project

  1. Open Google Cloud Console and pick (or create) a project at the top.
  2. Check the project name at the top before each step.

2. Enable the APIs

  • Google Drive API
  • Google Calendar API
  • Google Meet API

Press Enable on each.

3. Branding and audience

  1. Google Auth Platform → Get started.
  2. App name and support email.
  3. Audience: External (Internal is only for Google Workspace company accounts).
  4. Contact email, accept the terms, Create.

4. Scopes (Data Access)

Data Access → Add or remove scopes, tick these three, then Update and Save:

  • https://www.googleapis.com/auth/drive.file
  • https://www.googleapis.com/auth/calendar.events
  • https://www.googleapis.com/auth/meetings.space.created
drive.readonly (reading Drive folders for learning) is optional and restricted: users see a warning and Google may ask for a review. Add it only if you use a linked learning folder.

5. Publish the app (the key step)

Audience → Publishing status Testing → Publish app → Confirm. It must say In production.

In Testing, only listed test users can connect, and every connection stops by itself after 7 days.

6. Create the client

  1. Clients → Create client → Web application.
  2. JavaScript origins: each server's address, e.g. https://your-domain.com.
  3. Redirect URIs: two per server, e.g. https://your-domain.com/?drive_cb=1 and https://your-domain.com/?google_cb=1. The exact one is shown with a copy button on the backup page of each server.
  4. Untick “Use this client for an AI-powered agent”, then Create. Keep the Client ID and secret safe; never paste them in a chat.

7. Connect from the dashboard

  • System (super admin): Health, report and backup → Google Drive backup → paste the Client ID and secret → Connect Google. On “Google hasn't verified this app”: Advanced → Go to … (unsafe) → Continue.
  • A client's own account: My account → Google account → Connect my Google account (no Client ID needed).
  • Drive folders (optional): “Allow reading Drive folders” adds it to the same connection.
  • Check: press “Back up now” and see files uploaded. Every day at 10:13 the connection is tried; if it stopped you get a WhatsApp alert and a “Connect again” button.
